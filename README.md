# 🎬 Movie Recommendation System

A Machine Learning based Movie Recommendation System that recommends similar movies based on user-selected movies.

This project uses **Content-Based Filtering** with **Cosine Similarity** and provides an interactive web application using **Streamlit**.

---

## 📌 Project Overview

The Movie Recommendation System helps users discover similar movies according to their interests.

The system analyzes movie features and calculates similarity scores to recommend the most relevant movies.

## 🧠 Machine Learning Approach

### Content-Based Filtering

This system recommends movies by comparing movie features and finding similar movies.

### Workflow:

1. Data Collection
2. Data Cleaning
3. Feature Processing
4. Similarity Calculation
5. Movie Recommendation

### Algorithm Used:

**Cosine Similarity**

Cosine Similarity is used to measure similarity between movies and recommend the most similar movies.
